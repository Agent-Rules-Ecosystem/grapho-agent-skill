# 🔬 AST Code Analysis Principles

El Análisis de Árbol de Sintaxis Abstracta (AST) o parsing léxico permite inspeccionar la estructura del código sin ejecutarlo.

## Beneficios en Agentes de IA
1. **Determinismo**: Elimina la incertidumbre del LLM al listar archivos e imports.
2. **Desempeño**: Permite procesar 50,000 líneas de código en menos de 0.5 segundos.
3. **Métricas precisas**: Cuenta líneas efectivas de código (SLOC) e identifica el rol funcional del archivo por sus decoradores o imports.
